# odoo-zverp-modules Repository

This repository contains various Odoo modules that enhance functionality in different areas such as invoicing, contact management, sales, and accounting. TTTTTFFFF

## Modules

### `account_invoice_related_document`
**EN:** Adds a field in invoices to relate them to their originating document.  
**ES:** Añade un campo en las facturas que las relaciona con su documento de origen.

### `contact_history`
**EN:** Adds a field to track the contact's seniority.  
**ES:** Añade un campo para la antigüedad del contacto.

### `contacts_cuenta_contable`
**EN:** Adds columns in the contact list to display their associated accounting accounts.  
**ES:** Añade a la lista de contactos columnas con sus cuentas contables asociadas.

### `extended_description`
**EN:** Allows products to generate a note with a long description in documents when added.  
**ES:** Permite configurar en los productos que se cree una nota con una descripción larga en los documentos una vez que se añade el mismo.

### `extended_timesheet`
**EN:** Enables input of expenses and mileage in expense sheets.  
**ES:** Permite introducir gastos y kilometrajes en las hojas de gasto.

### `invoice_calendar`
**EN:** Adds a calendar view to monitor invoice due dates using color codes.  
**ES:** Añade una vista de calendario para poder observar las fechas de vencimiento de las facturas, con códigos de colores.

### `partner_account_autonumber`
**EN:** Creates sequential accounting accounts for new contacts based on Spanish localization.  
**ES:** Crea cuentas contables correlativas para los nuevos contactos basadas en la localización española.

### `sale_order_salesperson`
**EN:** Adds the salesperson's phone number next to the 'Salesperson' field in quotations.  
**ES:** Permite añadir el número de teléfono del comercial junto al campo 'comercial' en los presupuestos.

### `rectificativa_negativo`
**EN:** Prints corrective invoices with negative values.  
**ES:** Imprime las facturas rectificativas con valores negativos.

### `partner_matriculas`
**EN:** Allows associating multiple license plates with contacts, quotations, and invoices.  
**ES:** Permite asociar múltiples matrículas a contactos, presupuestos y facturas.
